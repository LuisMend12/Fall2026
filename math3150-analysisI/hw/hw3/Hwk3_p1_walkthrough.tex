\textbf{Goal.} Prove that for any $x,y\in\mathbb{R}$,
\[
  \bigl|\,|x|-|y|\,\bigr| \le |x-y| .
\]

\textbf{Tools.}
\begin{itemize}
  \item Triangle inequality: $|a+b|\le|a|+|b|$ for all $a,b\in\mathbb{R}$.
  \item For $c\ge 0$: \quad $|a|\le c \iff -c\le a\le c$.
\end{itemize}

% ============================================================
\section*{Step 1 (worked)}
Start from the identity
\[
  x = (x-y) + y .
\]
Take absolute values and apply the triangle inequality:
\[
  |x| = |(x-y)+y| \le |x-y| + |y| .
\]
Subtract $|y|$ from both sides:
\[
  |x|-|y| \le |x-y| . \tag{$\star$}
\]

% ============================================================
\section*{Step 2 (your turn)}
Do the same thing, but start from
\[
  y = (y-x) + x .
\]
Take absolute values and apply the triangle inequality:
\[
  |y| = |(y-x)+x| \le |y-x| + |x| .
\]
Subtract $|x|$ from both sides:
\[
  |y|-|x| \le |y-x| . \tag{$\star\star$}
\]

% ============================================================
\section*{Step 3 (combine)}
Let $a = |x|-|y|$ and $c = |x-y|$. Note that $c \ge 0$.
\paragraph{Step 1 gives $a \le c$.} Inequality $(\star)$ says
$|x|-|y| \le |x-y|$, which is literally $a \le c$.

\paragraph{Step 2 gives $-a \le c$.} Rewrite both sides of $(\star\star)$:
\begin{itemize}
  \item Left side: $|y|-|x| = -(|x|-|y|) = -a$.
  \item Right side: $y-x = -(x-y)$, and $|-t| = |t|$ for every real $t$,
        so $|y-x| = |x-y| = c$.
\end{itemize}
So $(\star\star)$ says $-a \le c$. Multiplying by $-1$ flips the
inequality: $a \ge -c$.

\paragraph{Together:}
\[
  -c \le a \le c .
\]

\paragraph{Which tool?} The triangle inequality has already been used.
The other tool,
\[
  |a| \le c \iff -c \le a \le c \qquad (c \ge 0),
\]
has exactly $-c \le a \le c$ on its right-hand side, so it gives the
left-hand side. (This is why we needed $c \ge 0$.)

\paragraph{Your turn:} write $|a| \le c$ with $a$ and $c$ replaced by
what they stand for. That one line is the statement of Problem 1.
